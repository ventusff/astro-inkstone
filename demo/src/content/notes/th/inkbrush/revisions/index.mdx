## ปูมประวัติ

แต่ละรายการแสดงว่าการแก้ไขเกิดขึ้นด้วยวิธีไหน (แก้ด้วยมือ แก้โดย Claude แปลด้วย AI นำเข้าจากกล่องขาเข้า หรือการย้อนคืนครั้งก่อนหน้า) โดยใคร พร้อม diff ก่อน/หลังที่พับเก็บได้ รายการระดับทั้งไฟล์ — การแปล การนำเข้า — ถูกจดไว้เป็นหลักฐานแต่ไม่มีปุ่มย้อนคืน: การย้อนของพวกนั้นเป็นงานของ git

## การย้อนคืน

คลิกปุ่มย้อนคืนของรายการหนึ่งครั้ง ข้อความ*หลัง*ของรุ่นนั้นจะถูกแทนที่ด้วยข้อความ*ก่อน*ของมัน — ในรูปการแก้ไขใหม่ที่ลงปูมตามปกติ การย้อนคืนจึงย้อนคืนตัวเองได้อีกที รายละเอียดสองข้อที่ควรรู้:

- การย้อนคืนใช้การจับคู่เนื้อหาแบบตรงตัวเป๊ะ ถ้าบล็อกถูกแก้ต่อจนข้อความเก่าไม่ปรากฏตามตัวอักษรอีกแล้ว การย้อนคืนจะถูกปฏิเสธแทนที่จะเดา — ไม่มีอะไรถูกปะแบบเดา ๆ เด็ดขาด
- ผลลัพธ์ต้องวิ่งผ่านด่านบิลด์เดียวกับการเซฟอื่นทุกครั้ง ([[inkbrush/editing|ตาข่ายนิรภัยสองผืน]]) การย้อนคืนที่จะทำให้หน้าพังถูกปฏิเสธ

## ทำไมต้องมีทั้งปูมและ git

git (ผ่าน `autocommit`) คือประวัติถาวรระดับทั้งไฟล์ — สิ่งที่คุณ push สำรอง และ diff ส่วนปูมคือชั้นละเอียดที่ทำให้ ⟲ ทันใจและทำงานรายบล็อก ทั้งสองตอบคนละคำถาม: *"เกิดอะไรขึ้นกับไฟล์นี้"* กับ *"เกิดอะไรขึ้นกับย่อหน้านี้"*
