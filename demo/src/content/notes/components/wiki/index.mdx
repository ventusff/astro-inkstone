Everything in this chapter runs **live** on this site: the landing page's shelves are `NoteCard`s, its facet rows are a `FacetNav`, and the meta strip above this very text is a `TaxonomyLine`. All of them are pure display components — the site resolves its registry and passes display-ready data. The resolution helpers ship in the package as `createTaxonomy` ([[three-way-split#where-the-browse-machinery-sits|mechanics in the package, meaning in the site]]).

## The binding, three lines

```ts title="src/lib/taxonomy.ts (this site's whole binding)"
import { createTaxonomy } from 'astro-inkstone/lib/taxonomy';
import { DOMAINS, KINDS, STATUSES } from '../content/notes/_meta/taxonomy';

export const { getWikiUnits, groupByKind, groupByDomain, groupByPrimaryDomain, tagIndex, resolveTaxonomy } =
  createTaxonomy({ kinds: KINDS, domains: DOMAINS, statuses: STATUSES },
    { collection: 'notes', locales: [{ code: 'zh', prefix: 'zh/' }], primary: 'en' });
```

The registry (`_meta/taxonomy.ts`) is pure data in the content tree: kinds, domains with tone colors, statuses with dot colors. Add a value there, tag a note with it, and every browse page picks it up — the routes are value-parameterized.

## FacetNav

The multi-dimension browse index — kinds, domains (with their tones), top tags, all as prerendered pill links:

<FacetNav
  base={base}
  kinds={[
    { def: { id: 'guide', label: 'Guide' }, count: 2 },
    { def: { id: 'reference', label: 'Reference' }, count: 4 },
    { def: { id: 'pattern', label: 'Pattern' }, count: 1 },
  ]}
  domains={[
    { def: { id: 'design', label: 'Design', tone: { bg: '#ece7f2', fg: '#5b4a8a' } }, count: 3 },
    { def: { id: 'pipeline', label: 'Pipeline', tone: { bg: '#e3efec', fg: '#2a6f62' } }, count: 2 },
  ]}
  tags={[
    { tag: 'tokens', count: 1 },
    { tag: 'markdown', count: 1 },
  ]}
  active={{ dim: 'kind', value: 'reference' }}
/>

Label strings are props with English defaults — a Chinese site passes `labels={{ kind: '形式', domain: '方向', tag: '标签', all: '全部 →' }}` and nothing else changes.
