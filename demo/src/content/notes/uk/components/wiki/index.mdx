## Прив’язка у три рядки

```ts title="src/lib/taxonomy.ts (уся прив’язка цього сайту)"
import { createTaxonomy } from 'astro-inkstone/lib/taxonomy';
import { DOMAINS, KINDS, STATUSES } from '../content/notes/_meta/taxonomy';

export const { getWikiUnits, groupByKind, groupByDomain, groupByPrimaryDomain, tagIndex, resolveTaxonomy } =
  createTaxonomy({ kinds: KINDS, domains: DOMAINS, statuses: STATUSES },
    { collection: 'notes', locales: [{ code: 'zh', prefix: 'zh/' }], primary: 'en' });
```

Реєстр (`_meta/taxonomy.ts`) — чисті дані в дереві вмісту: типи, напрями з тоновими кольорами, статуси з кольорами цяток, кожне значення з англійським і китайським підписами. Додайте там значення, позначте ним нотатку — і кожна сторінка перегляду підхопить його сама: маршрути параметризовано за значеннями.

## Полиця та її токени

Сторінки перегляду стоять на другому тлі: теплий папір, шапка із засічками, двопунктова лінійка полиці й сітка карток — усе це дає `browse.css` через токени `--wb-*`, тобто полична половина [[design-tokens|двоконтекстної палітри]]. Сторінка входить у контекст одним класом `wb-root` на body; всередині нього токени оздоблення перевідображено, тож та сама панель навігації однаково доречна і на папері читання, і на папері полиці.

## NoteCard

Картка приймає готові до показу дані — розв’язані підписи, тони, відформатовану дату, посилання на дзеркала. Картки живуть на полиці, тож зразок сидить у вкрапленні поличного контексту (`.wb-root.wb-inset`) посеред цієї колонки читання:

## FacetNav

Багатовимірний покажчик перегляду — типи, напрями (з їхніми тонами), найуживаніші теги, усе як попередньо відрендерені посилання-пігулки:

<FacetNav
  base={`${base}/uk`}
  kinds={[
    { def: { id: 'guide', label: 'Інструкція' }, count: 2 },
    { def: { id: 'reference', label: 'Довідник' }, count: 4 },
    { def: { id: 'pattern', label: 'Патерн' }, count: 1 },
  ]}
  domains={[
    { def: { id: 'design', label: 'Дизайн', tone: { bg: '#ece7f2', fg: '#5b4a8a' } }, count: 3 },
    { def: { id: 'pipeline', label: 'Пайплайн', tone: { bg: '#e3efec', fg: '#2a6f62' } }, count: 2 },
  ]}
  tags={[
    { tag: 'tokens', count: 1 },
    { tag: 'markdown', count: 1 },
  ]}
  active={{ dim: 'kind', value: 'reference' }}
  labels={{ kind: 'Тип', domain: 'Напрям', tag: 'Теги', all: 'Усі →' }}
/>

Рядки підписів — теж пропси з англійськими типовими значеннями: у зразку вище передано `labels={{ kind: 'Тип', domain: 'Напрям', tag: 'Теги', all: 'Усі →' }}` — ті самі слова, що й на українських сторінках рубрик цього саду; більше нічого міняти не треба.

## TaxonomyLine, KindBadge, StatusDot, DomainChip

Однорядкова смужка метаданих на чолі нотатки збирає докупи три атоми-значки; кожен придатний і сам по собі:

<TaxonomyLine
  kind={{ id: 'pattern', label: 'Патерн' }}
  domains={[{ id: 'design', label: 'Дизайн', tone: { bg: '#ece7f2', fg: '#5b4a8a' }, href: `${base}/uk/domain/design/` }]}
  status={{ id: 'growing', label: 'Росте', dot: '#5c8a3c' }}
  updated="2026.08"
/>

Атоми поодинці, просто в рядку тексту: значок типу <KindBadge def={{ id: 'guide', label: 'Інструкція' }} />, чип напряму <DomainChip def={{ id: 'pipeline', label: 'Пайплайн', tone: { bg: '#e3efec', fg: '#2a6f62' } }} href={`${base}/uk/domain/pipeline/`} /> і цятка статусу <StatusDot def={{ id: 'evergreen', label: 'Вічнозелена', dot: '#1f5e46' }} />.

## Backlinks

Панель «Зворотні посилання» під кожною нотаткою цього саду обчислює пакетний `createBacklinks`: власний розв’язувач вікіпосилань рушія, обернений на покажчик «ціль ← джерела», разом із фрагментами контексту. Тут — зі зразковими даними:

<Backlinks
  items={[
    {
      href: `${base}/uk/kitchen-sink/`,
      title: 'Демонстраційний стенд',
      before: 'семиколонкова таблиця — водночас ',
      label: 'шпаргалка варіантів callout',
      after: ' і жива перевірка перекладання на картки…',
    },
    {
      href: `${base}/uk/design-tokens/`,
      title: 'Дворівнева палітра й теми',
      before: 'компоненти споживають лише ',
      label: 'семантичний рівень',
      after: ', тож зміни ідентичності їх не торкаються.',
    },
  ]}
/>

Догорніть до низу цієї сторінки — там справжня панель: цей розділ сам є ціллю вікіпосилань.

## LocalGraph

Той самий покажчик відповідає й на друге запитання — *що лежить за один крок звідси?* — і `index.localGraph(id, titleOf)` повертає відповідь списком сусідів, вхідні першими. Компонент розкладає їх еліпсом довкола нотатки: вхідні суцільною лінією, вихідні пунктиром; сусід може нести власний `color` (скажімо, з іншої колекції). Нижче — на ширину колонки, зі зразковими даними; справжній граф сидить у бічній панелі кожної нотатки, що має посилання:

<div style="max-width: 300px">
  <LocalGraph
    centerTitle="Вікі та перегляд"
    neighbors={[
      { id: 'kitchen-sink', title: 'Демонстраційний стенд', href: `${base}/uk/kitchen-sink/`, dir: 'in' },
      { id: 'design-tokens', title: 'Дворівнева палітра', href: `${base}/uk/design-tokens/`, dir: 'out' },
      { id: 'three-way-split', title: 'Поділ натроє', href: `${base}/uk/three-way-split/`, dir: 'out' },
      { id: 'checks', title: 'Перевірки', href: `${base}/uk/checks/`, dir: 'in', color: 'var(--color-accent4)' },
    ]}
  />
</div>
