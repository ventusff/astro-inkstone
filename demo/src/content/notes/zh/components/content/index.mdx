## Callout

五个变体;`title` 覆盖内置标签。引用语法与裸 HTML 两种写法见[[kitchen-sink|全要素演示]]。

<Callout variant="intuition" title="什么时候用组件形态">
  MDX 里内容随手写的时候。纯 Markdown 文件用引用语法;两者渲染出同一套标记。
</Callout>

## Chip

行内徽章,标状态或分类:<Chip variant="teal">稳定</Chip> <Chip variant="mustard">测试中</Chip> <Chip variant="violet">研究</Chip>——也可传自定义色调做主题色板:<Chip tone={{ bg: '#e8f0ee', fg: '#1f5f56' }}>自定义色调</Chip>

## Grid

一套栅格,三种皮(`plain`、`card`、`cmp`)。卡片:

<Grid cols={2} kind="card">
  <div>
    **先 token。**引入顺序是契约的一部分:token、内容层、站点 chrome,依次来。
  </div>
  <div>
    **只碰语义层。**组件从不写裸色值——换掉色板,它们全体跟着走。
  </div>
</Grid>

对照皮,专为前后对比:

<Grid cols={2} kind="cmp">
  <div>
    **没有守门**——漏了闭合的 `**` 以两个字面星号的样子上线。
  </div>
  <div>
    **有守门**——构建当场失败,精确到 file:line:column,插标压在肇事标记下面。
  </div>
</Grid>

## Steps

竖轨上的 markdown 列表:

<Steps>
1. 加两个 submodule 与 `file:` 依赖。
2. 全局样式表里引入 `tokens.css` 与 `base.css`。
3. `astro.config` 里接上 `siteMarkdown()`。
4. 用你的身份色覆盖第一层色板。
</Steps>
