## 어디에 놓이는가

엔진은 CMS 기능 **그리고** 콘텐츠 가드가 딸린 Markdown 방언을 소유합니다 — 편집기가 받아들이는 문법과 페이지가 렌더링하는 문법은 하나의 문법이어야 하므로, 한 번 쓰여 어디서나 소비됩니다(경계선이 왜 거기 그어졌는지는 [[three-way-split|세 갈래 분할]]이 설명합니다). 스타일은 종이 계층의 것이고, 아이덴티티는 여러분 사이트의 것입니다. 이 페이지들에 렌더링된 모든 것 — 이 글 위의 스트립까지 — 은 종이가 일하는 모습이고, 이 페이지들을 *편집하는* 모든 것은 엔진입니다.
