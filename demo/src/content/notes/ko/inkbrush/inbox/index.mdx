## 켜는 법

수신함은 꺼진 채 배포됩니다. `inkbrush.config.ts` 파일에서 켭니다:

```ts title="inkbrush.config.ts"
inbox: {
  dir: '~/vault/inbox',        // 감시할 폴더 (~/ 지원)
  ignore: ['daily-'],          // 선택: 건너뛸 파일명 접두사
},
```

시작 시점에 폴더에 이미 있던 파일은 가져오는 대신 본 것으로 표시됩니다 — 그 *이후에* 추가된 노트만 자동으로 동기화됩니다. 더 오래된 것은 API를 통해 명시적으로 소급해 들여올 수 있으므로, 수신함을 켰다고 십 년 치 볼트 이력이 느닷없이 사이트에 쏟아지는 일은 없습니다.

## 가져오기가 하는 일

들어오는 노트 하나하나는 복사되는 것이 아니라 변환됩니다:

- 이미지 임베드는 볼트의 자산 폴더를 상대로 해석되고, 파일은 **가져온 노트 바로 곁에 복사되며**, 임베드는 표준 이미지 문법이 됩니다 — 나중에 노트를 지우면 자산도 함께 지워집니다
- 사이트의 실제 노트와 일치하는 `[[위키링크]]` 표기는 링크로 살아남아 [[inkbrush/wikilinks|어디서나 같은 해석 규칙]]으로 해석되고, 나머지는 경고와 함께 평범한 강조로 펴집니다
- 하이라이트는 진짜 `<mark>` 요소가 되고, frontmatter 메타데이터는 제목 아래의 출처 줄이 되며, 설명은 첫 번째 실속 있는 문단에서 끌어냅니다

변환된 노트는 이어서 수동 저장과 같은 빌드 관문을 통과해야 합니다 — 페이지를 깨뜨릴 노트는 가져와지는 대신 거부됩니다.

모든 가져오기는 수정 일지에 파일 전체 단위 기록(via: inbox)으로 남습니다: [[inkbrush/revisions|⟲]] 목록에 감사 행으로 나타나고, 가져오기를 무르는 일은 git 작업입니다. `autocommit` 옵션이 켜져 있으면 각 가져오기도 다른 편집처럼 git 커밋이 되고, 꺼져 있으면 가져온 파일은 직접 검토하고 커밋할 평범한 워킹 트리 변경으로 도착합니다.
