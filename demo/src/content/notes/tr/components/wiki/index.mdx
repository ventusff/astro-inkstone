## Bağlama: üç satır

```ts title="src/lib/taxonomy.ts (bu sitenin bütün bağlaması)"
import { createTaxonomy } from 'astro-inkstone/lib/taxonomy';
import { DOMAINS, KINDS, STATUSES } from '../content/notes/_meta/taxonomy';

export const { getWikiUnits, groupByKind, groupByDomain, groupByPrimaryDomain, tagIndex, resolveTaxonomy } =
  createTaxonomy({ kinds: KINDS, domains: DOMAINS, statuses: STATUSES },
    { collection: 'notes', locales: [{ code: 'zh', prefix: 'zh/' }], primary: 'en' });
```

Kayıt defteri (`_meta/taxonomy.ts`) içerik ağacında saf veridir: türler, ton renkleriyle alanlar, nokta renkleriyle durumlar — her değerin kendi dillerindeki görünen etiketleriyle. Oraya bir değer ekleyin, bir notu onunla etiketleyin; her göz atma sayfası onu kendiliğinden yakalar — rotalar zaten değere göre parametrelidir.

## Raf ve token’ları

Göz atma sayfaları ikinci bir zeminde durur: sıcak kâğıdı, serif site başlığını, rafın çift puntoluk çizgisini ve kart ızgarasını onlara `browse.css`, `--wb-*` token’ları üzerinden verir — [[design-tokens|iki bağlamlı paletin]] göz atma yarısı. Bir sayfa bu bağlama body’sindeki tek bir sınıfla girer: `wb-root`; bağlamın içinde chrome token’ları yeniden eşlenir, böylece aynı gezinme çubuğu iki zeminde de oturur.

## NoteCard

Bir kart, görüntülenmeye hazır veri alır — çözülmüş etiketler, tonlar, biçimlenmiş bir tarih, ayna bağlantıları. Kartların evi raftır; bu yüzden örnek, okuma sütununun içine gömülü küçük bir raf bağlamı parçasında (`.wb-root.wb-inset`) duruyor:

## FacetNav

Çok boyutlu göz atma dizini — türler, alanlar (kendi tonlarıyla), öne çıkan etiketler; hepsi önceden çizilmiş hap bağlantılar hâlinde:

<FacetNav
  base={`${base}/tr`}
  kinds={[
    { def: { id: 'guide', label: 'Rehber' }, count: 2 },
    { def: { id: 'reference', label: 'Referans' }, count: 4 },
    { def: { id: 'pattern', label: 'Desen' }, count: 1 },
  ]}
  domains={[
    { def: { id: 'design', label: 'Tasarım', tone: { bg: '#ece7f2', fg: '#5b4a8a' } }, count: 3 },
    { def: { id: 'pipeline', label: 'İşlem hattı', tone: { bg: '#e3efec', fg: '#2a6f62' } }, count: 2 },
  ]}
  tags={[
    { tag: 'tokens', count: 1 },
    { tag: 'markdown', count: 1 },
  ]}
  active={{ dim: 'kind', value: 'reference' }}
  labels={{ kind: 'Tür', domain: 'Alan', tag: 'Etiketler', all: 'Tümü →' }}
/>

Satır etiketleri de props’tur ve varsayılanları İngilizcedir — yukarıdaki örnek `labels={{ kind: 'Tür', domain: 'Alan', tag: 'Etiketler', all: 'Tümü →' }}` geçiyor, bu sitenin Türkçe dizin sayfalarının geçtiğinin aynısını; başka hiçbir şey değişmez.

## TaxonomyLine, KindBadge, StatusDot, DomainChip

Bir notun başındaki tek satırlık üstveri şeridi, üç rozet atomunun birleşimidir; her atom tek başına da kullanılabilir:

<TaxonomyLine
  kind={{ id: 'pattern', label: 'Desen' }}
  domains={[{ id: 'design', label: 'Tasarım', tone: { bg: '#ece7f2', fg: '#5b4a8a' }, href: `${base}/tr/domain/design/` }]}
  status={{ id: 'growing', label: 'Büyüyor', dot: '#5c8a3c' }}
  updated="2026.08"
/>

Atomlar tek başlarına, akan bir satırda: bir <KindBadge def={{ id: 'guide', label: 'Rehber' }} /> tür rozeti, bir <DomainChip def={{ id: 'pipeline', label: 'İşlem hattı', tone: { bg: '#e3efec', fg: '#2a6f62' } }} href={`${base}/tr/domain/pipeline/`} /> alan çipi, bir <StatusDot def={{ id: 'evergreen', label: 'Her dem yeşil', dot: '#1f5e46' }} /> durum noktası.

## Backlinks

Bu bahçede her notun altındaki "geri bağlantılar" paneli, paketin `createBacklinks` yardımcısıyla hesaplanır — motorun kendi wikilink çözücüsü, hedef ← kaynaklar dizinine ters çevrilir; bağlam parçacıkları da yanında gelir. Burada satır içi örnek veriyle:

<Backlinks
  items={[
    {
      href: `${base}/tr/kitchen-sink/`,
      title: 'Hepsi bir arada',
      before: 'yedi sütunlu tablo aynı zamanda ',
      label: 'callout kopya kâğıdı',
      after: ' ve bir karta dönüşme sınamasıdır…',
    },
    {
      href: `${base}/tr/design-tokens/`,
      title: 'İki katmanlı palet ve temalar',
      before: 'bileşenler yalnızca ',
      label: 'anlamsal katmanı',
      after: ' tüketir; kimlik değişiklikleri onlara hiç dokunmaz.',
    },
  ]}
/>

Gerçeğini görmek için bu sayfanın dibine inin — bu bölümün kendisi bir wikilink hedefidir.

## LocalGraph

Aynı dizin ikinci bir soruyu da yanıtlar — *buradan bir adım ötede ne var?* — ve `index.localGraph(id, titleOf)` bunu, gelenler önde olmak üzere bir komşu listesi olarak döndürür. Bileşen komşuları notun çevresindeki bir elips üzerine çizer: gelen bağlantılar düz, gidenler kesik çizgiyle; bir komşu kendi `color` değerini de taşıyabilir (örneğin ikinci bir koleksiyondan). Burada sütun genişliğinde, örnek veriyle; gerçeği, bağlantısı olan her notun kenar çubuğundadır:

<div style="max-width: 300px">
  <LocalGraph
    centerTitle="Wiki ve göz atma"
    neighbors={[
      { id: 'kitchen-sink', title: 'Hepsi bir arada', href: `${base}/tr/kitchen-sink/`, dir: 'in' },
      { id: 'design-tokens', title: 'İki katmanlı palet', href: `${base}/tr/design-tokens/`, dir: 'out' },
      { id: 'three-way-split', title: 'Üçlü ayrım', href: `${base}/tr/three-way-split/`, dir: 'out' },
      { id: 'checks', title: 'Denetimler', href: `${base}/tr/checks/`, dir: 'in', color: 'var(--color-accent4)' },
    ]}
  />
</div>
