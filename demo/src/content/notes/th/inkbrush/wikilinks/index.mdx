## เป้าหมายเป็นอะไรได้บ้าง

เป้าหมายไม่จำเป็นต้องเป็น id ของบันทึก การแก้ปลายทางไล่ลองตามลำดับ: **มิเรอร์ของภาษาปัจจุบัน**ก่อน (ลิงก์บนหน้าพี่น้องทั้งสิบเจ็ดฉบับของหน้านี้จะลงที่ฉบับภาษาเดียวกันของเป้าหมาย และถอยไปหาบันทึกต้นฉบับเฉพาะเมื่อไม่มีมิเรอร์) แล้วจึง id แบบตรงตัว ตามด้วยนามแฝง ชื่อ brand และชื่อเรื่อง โดยไม่แยกตัวพิมพ์เล็กใหญ่ บทความ[[garden-craft|ว่าด้วยการดูแลสวน]]ประกาศ `tending` ไว้เป็นนามแฝง การเขียน `[[tending]]` จึงลงเอยที่หน้าเดียวกัน anchor กับป้ายข้อความประกอบกันได้อย่างที่หวัง: `[[garden-craft#pruning]]` พาดิ่งไปที่หัวข้อโดยตรง `[[garden-craft|the gardening essay]]` เรนเดอร์ข้อความกำหนดเอง — และทั้งสองแบบใช้ร่วมกันได้

## ลิงก์เสียไม่ทำให้บิลด์ล้ม

ลิงก์ไปหาบันทึกที่ไม่มีอยู่เรนเดอร์เป็นลิงก์เสียที่มองเห็นได้ชัด พร้อมเหตุผลใน tooltip และบิลด์บันทึกคำเตือนไว้ นี่คือทางเลือกที่จงใจสำหรับสวน: บันทึกที่ยังไม่ได้เขียนคือคำเชื้อเชิญ ไม่ใช่ข้อผิดพลาด เป้าหมายที่ตรงกับหลายบันทึกพร้อมกันเรนเดอร์แบบเดียวกัน โดยติดเครื่องหมายว่ากำกวม ส่วนลิงก์ผุ ๆ ยังคงเป็นธุระของ CI — CLI `check-wikilinks` ของเอนจินแก้ปลายทางทุกลิงก์ด้วยกติกาของตัวไลบรารีเอง และในโหมด `--strict` เปลี่ยนลิงก์เสียให้เป็น exit ล้มเหลว ซึ่ง repo นี้ก็รันแบบนั้นอยู่ ([[checks|การตรวจสอบห้าด่าน]])

## เขียนครั้งเดียว ใช้ในสี่ที่

หน้าเว็บ พรีวิวสดของตัวแก้ไข [[inkbrush/inbox|ตัวนำเข้าจากกล่องขาเข้า]] และ lint ใน CI แก้ปลายทางด้วยโค้ดชุดเดียวกัน — ลิงก์จึงมีความหมายเหมือนกันทุกที่ และตัวแก้ไขก็ใจดีได้เต็มที่: พิมพ์ `[[` ในโหมดแก้ไข แล้วรายการเติมคำอัตโนมัติจะเด้งขึ้นมา ครอบคลุมทั้ง id ชื่อเรื่อง และนามแฝง
