## Notas pequenas, densamente ligadas

Uma nota de jardim paga o próprio aluguel sendo pequena o bastante para ser terminada e bem ligada o bastante para ser encontrada. Prefira cinco notas ligadas a uma página que se esparrama; deixe os [[inkbrush/wikilinks|wikilinks]] carregarem a estrutura no lugar de um sumário. Links mortos fazem parte do método — cada um é uma nota que você deve a si mesmo.

## Poda

Notas velhas apodrecem de dois jeitos: ficam erradas, ou ficam órfãs. O erro é o caso fácil — edite o bloco culpado onde você o vê, e o diário lembra o que ele dizia antes (o [[inkbrush/revisions|histórico de revisões]] tem os detalhes). Órfãs pedem poda: ligue-as ao resto, funda-as em outra nota ou apague-as sem culpa. Um jardim é julgado pelo que mantém vivo, não pelo que acumulou.

## Deixe as ferramentas carregarem a cerimônia

Commits, histórico, backups — a cerimônia é real, mas não deveria ser sua. Com `autocommit` ligado, os salvamentos viram commits de git por conta própria; as importações chegam da [[inkbrush/inbox|caixa de entrada]] por conta própria; até as traduções são um clique na [[inkbrush/ai-assist|assistência de IA]] — as dezoito edições deste jardim dizem até onde isso vai. O que sobra para você é a única parte que sempre foi interessante: ter algo a dizer.
