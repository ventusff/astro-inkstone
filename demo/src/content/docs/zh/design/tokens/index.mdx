## 两层架构

`styles/tokens.css` 是全站色板的唯一事实源,分两层:

**第 1 层:原始色板**——用纸墨颜料命名的常量,主题不变。纸有素、帛、页、简、笺(页底/次级面/卡面/代码底/公式底),墨有玄、黛墨、淡墨、界,颜料有朱、黛、赭、紫,深色专用一组「夜」与「月白」。变量名以 `--p-` 开头:

```css title="tokens.css(第 1 层节选)"
--p-paper: #fbf9f4; /* 素 · 页底 */
--p-ink: #25313a; /* 玄 · 正文 */
--p-vermilion: #c14b02; /* 朱 · 主强调(AA 压深档,4.7:1) */
--p-vermilion-raw: #fe5d01; /* 朱 · 原色(字形/图形专用,永不作正文链接) */
```

**第 2 层:语义 token**——`--color-bg`、`--color-ink`、`--color-accent` 这些按用途命名的变量,浅色在 `:root` 里指向第 1 层,深色在 `[data-theme='dark']` 里整组换指向。**组件层(`base.css` 与全部组件)只准消费这一层**,新增规则不得写裸色值——这是包的硬纪律。

## 站点怎么定制身份

只覆盖第 1 层。把 `--p-vermilion` 换成你的品牌色,语义层与组件层原封不动跟着走,深浅两个主题同时生效:

```css title="站点 site.css"
:root {
  --p-vermilion: #b03a48;
  --p-vermilion-text: #93303c; /* 小字档独立加深,见下节 */
}
```

本示范站刻意一个变量都不覆盖——你现在看到的就是包的默认色板。

## 对比度是审定过的

tokens 里的每个值都按 WCAG AA 在它出现的每种底色上逐条审定:小字 4.5:1 起步;强调色的**文字档**独立加深(`--p-vermilion-text`、`--p-mustard-text`),因为强调橙拿去写 12.5px 小标题时,衬底往往正是它自己的浅色调;深色主题另给一组提亮档。改任何一个值之前,先想清楚它衬在哪些底上。

## 浅色是身份

主题有意**不读** `prefers-color-scheme`:读者在同族站点之间移动时,页面不得自行翻转主题。深色只经 `[data-theme='dark']` 生效,由站点自备的开关切换(本站导航条右侧的日/月按钮,选择存在 `localStorage` 的 `inkstone-theme` 键下,首帧前由 ThemeInit 内联脚本回放,深色读者不会看到米色闪一下)。

## 字体也在这一层

代码字体是 Maple Mono CN 的固定字符集子集(ASCII + 框线符号 + 常用汉字 3500 + 既有内容字符并集):Latin 0.6em、汉字 1.2em——**汉字恰好两个字符宽**,框线图在中英混排下也对得齐。子集配方与再生成脚本随包(`fonts/build_font_subset.py`),内容新增生僻字超出覆盖时重跑脚本再提交 woff2。正文衬线与 UI 无衬线字体栈同样定义在 tokens 里(`--font-body`、`--font-ui`、`--font-mono`)。
