## 修订日志

每条记录标明这次改动怎么来的(手工编辑、Claude 编辑、AI 翻译、收件箱导入,或更早的一次回退)、经谁之手,并附一份可折叠的改前/改后对比。整篇级别的记录——一次翻译、一次导入——列出来备查,但不带回退按钮:撤销它们是 git 的事。

## 回退

点一下某条记录的回退按钮,那次修订的*改后*文字就换回*改前*文字——它本身也作为一次新的日志化编辑记录在案,所以回退本身也能再回退。两个细节值得知道:

- 回退按内容精确匹配来套用。这个块若后来又被改过、旧文字已不再逐字出现,回退会被拒绝而不是靠猜——绝不做模糊拼补。
- 回退的结果和任何保存一样,要过同一道构建关([[inkbrush/editing|两道保险]])。会弄坏页面的回退,照样被拒。

## 有了 git,为什么还要日志

git(经 `autocommit`)是持久的、整文件粒度的历史——推送、备份、diff 都靠它。日志是让 ⟲ 即点即出、精确到块的那层细账。两者回答的不是同一个问题:*「这个文件发生过什么」*对*「这一段发生过什么」*。
