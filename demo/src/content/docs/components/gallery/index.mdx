Everything on this page is imported from `astro-inkstone/components/` by path and rendered with the package's default tokens. Components are presentational: they take data and label strings as props (English defaults), so a site in any language passes its own.

## Callout

Five variants; `title` overrides the built-in label. The [kitchen sink](../../writing/kitchen-sink/) shows the quote-syntax and raw-HTML spellings of the same visual.

<Callout variant="intuition" title="When to reach for the component">
  In MDX, when the content is authored inline. The quote syntax covers plain-Markdown files; both render identical markup.
</Callout>

## Steps

A markdown list on a vertical rail:

<Steps>
1. Add the two submodules and the `file:` dependencies.
2. Import `tokens.css` and `base.css` in your global stylesheet.
3. Wire `siteMarkdown()` into `astro.config`.
4. Override the tier-one palette with your identity color.
</Steps>

## DemoMount — live

The mount is the package's; the module and loader are the site's (`src/lib/demo-loader.ts` here — the layout calls `mountAllDemos()` once). This one draws two-source wave interference with the page's own ink token, so it follows the theme:

<DemoMount demo="waves/interference" title="Demo · Two-source wave interference" canvas={{ w: 640, h: 300 }}>
  <Fragment slot="caption">
    Two point sources emit circular waves; where crests meet crests the ink pools, where crests meet troughs the paper shows through. Toggle the theme — the demo re-inks itself from the live tokens.
  </Fragment>
</DemoMount>

## And the rest

`Hero` and `PartHero` are page/part headers the demo's own cover doesn't need; `LocalToc` renders the "on this page" jump list you see above; `PageFooter` is the small print at the page foot; the `wiki/*` set (NoteCard, FacetNav, KindBadge, StatusDot, DomainChip, TaxonomyLine) powers faceted note browsing and binds to your taxonomy through `createTaxonomy()` — see the package README for the three-line binding.
