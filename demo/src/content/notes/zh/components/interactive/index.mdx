## DemoMount 现场演示

分工还是这个包一贯的分法:**挂载标记**(舞台、控件槽、图注槽)随包提供;**演示模块和它的加载器**归站点所有。本站把加载器放在 `src/lib/demo-loader.ts`,在布局里调用一次 `mountAllDemos()`;这个调用每页都执行,但只有页面上真的带着 `[data-demo]` 挂载点,才会去拉取对应演示模块的 chunk。

要在画布上接收指针输入的演示,传 `interactive`——舞台随即接管触摸手势并显示十字准星。这一个是被动的(只渲染),所以不传这个开关,在画布上滑动仍然是翻页。它用页面自己的墨色 token 画双源波干涉,所以跟着主题走:

<DemoMount demo="waves/interference" title="演示 · 双源波干涉" canvas={{ w: 640, h: 300 }}>
  <Fragment slot="caption">
    两个点源发出圆形波;波峰遇上波峰,墨色汇聚,波峰遇上波谷,纸色透出来。切换一下主题——演示会从实时 token 里重新取墨。
  </Fragment>
</DemoMount>

模块契约只有一条:默认导出一个 `mount(ctx)`,返回清理函数;像 `waves/interference` 这样的模块 id 怎么解析,全由站点自定(本站用 `import.meta.glob`)。

演示也可以放在展示它的那一页旁边,不经站点自己的加载器:用 `module` 写出模块从站点根算起的路径,由引擎加载(`lib/page-demos.ts` 找出 `src/content/` 下的每个 `.ts`)。模块拿到挂载点的 `root`、`stage`、`canvases`、`controls` 和页面的 `locale`,再用 `inLocale`(`lib/figure-file.ts`)从旁边的 JSON 取出文字;所以英文页和这一页用的是同一个模块、同一个文件,各显示各的语言:

## 页面配件

剩下这些组件不填充笔记,而是给笔记搭框:

- `Hero` 给一篇笔记开场:眉题、展示标题、一段走完整 markdown 管线的导语、一行元信息,还有可选的 `tocLabel`——它会在侧栏加一行不编号的「引子」。frontmatter 的 `title` 仍是给 `<title>` 与卡片用的简短正名;hero 的标题可以写长。
- `PartHero` 给 hub 的一章开场——本页页头就是它。它的眉题从来不用手写:路由把这一章的「第 III 部 · …」标签作为 `props.partLabel` 传进来。
- `Part` 把一篇长的单页笔记切成几部;编号预设把它变成侧栏里「PART II · …」那样的分组行。[[kitchen-sink|全要素演示]]就是这么切的。
- `HubCard` 与 `.hub-grid` 是 hub 落地页的卡片,`.path` 是它的阅读路径框——两样都在[[components|本合集的总览页]]上。
- `LocalToc` 渲染页内跳转列表;两种编号预设产出的两种 ToC 形状它都接受,条目数低于可配置的下限时自动隐藏。下面就拿本章自己的 ToC 现场演示。
- `SidebarMemory` 让可滚动的侧栏跨页面记住读者上次停的位置,当前项(默认认 `[aria-current="page"]`)快要滚出视野时自动居中。把它放进侧栏的滚动盒里、导航标记之后;它在首次绘制前运行,侧栏不会先闪到顶部再跳回来。本站的侧栏就装着它。
- `LineageSvg` 把不含文字的 SVG(谱系树、分类树)装成卡片;带文字的图用 `FlowDiagram`,见下文。
- `PageFooter` 是笔记脚下那行小字——本站每篇笔记底下那行就是。
- 导览类组件在[[components/wiki|wiki 与导览一章]];本合集的 markdown 侧则是[[kitchen-sink|全要素演示]]。

## FlowDiagram——按字自适应的框

带文字的图一律用 `FlowDiagram`(或 `mermaid` 代码块)。手写坐标的 `<svg>` 加 `<text>` 是对着一种字体画的,换一种更宽的字体就出框——而每个站用的字体都不一样;`LineageSvg` 只留给不含文字、字体宽窄影响不了形状的 SVG。图的内容是数据:`cols`、`nodes`(`col` / `row` / `span`、`tone`、`lines`、`tag`、虚线说明框 `ghost`、等宽小字 `mono`)、`edges`(`label`、`dashed`、断线 `off`),可选 `lanes` 与 `heads`:

## Deck——用一篇笔记做的演示稿

`Deck` 把它包住的内容做成一叠幻灯片:单独一行的分隔线(`---`,前面空一行)结束一张。内容仍是笔记自己的块,所以站点把整篇笔记的 `<Content />` 包进 `Deck`,幻灯片里照样能就地编辑、写双链、用所有组件。读者看到的是一叠 16:9 的幻灯片;按**放映**,从眼前这张起一次放一张、铺满屏幕。每张都排在 960 × 540 的画布上、按显示宽度缩放,所以在页面栏里、投影上、打印出来(一页一张,10 × 5.625 英寸)都一样;手机上按栏宽排、不缩放。

一张幻灯片的样子由标记决定。标记是自闭合的组件,自己就是一个块,什么都不包,所以这张上别的块仍各自能编辑:

- `<Layout name="…" />` 放在一张的开头,给出它的版式:`cover`、`section`、`center`、`default`、`full`、`image`、`image-left`、`image-right`、`two-cols`、`quote`、`fact`、`statement` 或 `end`。没有这个标记的是 `default`;只有一个标题、至多一段话的是 `section`。`section` 开始一个部分,这一部分每张的角上都印着它的名字。
- `<Column />` 结束一栏、开始下一栏;开头的标题横跨所有栏。
- `<Build />` 之后的块在放映时一次点击出来一个,列表一次出来一项。带 `steps` 的 `FlowDiagram` 随点击逐个点亮框和连线(`steps[k]` 写第 k + 1 次点击点亮什么,框写 id,连线写 `'from>to'`);别的组件用 `lib/deck.ts` 的 `onDeckStep` 听 `deck:step` 事件,跟着自己的点击变化。
- `<Stretch />` 让它后面那个块长到这张剩下的高度:图片或框图要尽量大时用它。

放映时:→ ↓ 空格 PageDown 前进一次点击,← ↑ PageUp 后退一次,Home 和 End 跳到头尾,**O** 打开概览(所有幻灯片排成网格,点一张跳过去,每个 `section` 另起一行),Esc 退出,触屏左右滑翻页。换张、换点击都是 view transition:相邻两张共有的标题或图片留在原处、平滑变形过去。位置记在地址的 `#` 后面:`#/3` 是第三张,`#/3.2` 是它的第二次点击,所以链接打开就在复制它的地方,刷新后也回到同一张、同一次点击。

不止一处要用的图,存成一个 JSON 文件,放在回答它的那一页旁边,由 `FigureFile` 画出:文件里有 `title`、可选的 `caption` 和 `flow`(一份 FlowDiagram 的 spec,`steps` 也在里面),每处文字都是一个各语言的对象(`{ "en": …, "zh": … }`)。每一处都按从站点根算起的路径 import 它(`import deckPipeline from '/src/content/notes/components/interactive/deck-pipeline.json'`),站点不用另设别名,改一次文件处处都变。某种语言还没有的文字,显示图的原文语言,也就是 `title` 的第一个键。同一个文件,这里完整显示一次,下面再在一张幻灯片上随点击逐个点亮:

## 没有组件形态的配件

有几件配件只是 `base.css` 里的普通类,留给站点在自己的布局里渲染,或在行文里直接写 HTML:

| 类 | 是什么 |
| --- | --- |
| `.page-head` + `.kicker`、`.page-desc`、`.page-date` | 由 frontmatter 驱动的页头(眉题、h1、描述、日期),由布局渲染,替代 `<Hero>` |
| `.banner`、`.banner-fallback` | 页头下面的一行通告;fallback 变体是弱化样式的那种 |
| `.page-foot` | 两栏小字页脚(左槽、右槽) |
| `.speak` | 深入小节标题下的大白话注解;标签文案在 `--speak-label` |
| `.path` + `.title`、`.route`、`.arrow` | hub 上的阅读路径框 |
| `.ref-tag` | 文献列表里的等宽小标签(会议名、年份) |
| `.tag`、`.tag.teal / .mustard / .violet` | 论文卡同款徽章,哪里都能用 |
| `.measured` + `.measured-head`、`.measured-body`、`.measured-pane`(`.doc`)、`.measured-tag` | 「文档说 vs 实测」对比卡:一条实心青色标题栏压着两栏,`.doc` 栏放文档的说法,另一栏放测量结果——轮廓和任何 callout 都不一样 |
| `.paper .idea-label` | `PaperCard` 正文里的大写小标签,如 `<span class="idea-label">Key idea</span>` |
