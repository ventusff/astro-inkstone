## DemoMount — ของจริง

การแบ่งงานเป็นแบบเดียวกับที่แพ็กเกจทำเสมอ: **มาร์กอัปจุดยึด** (เวที ช่องปุ่มควบคุม ช่องคำบรรยาย) มากับแพ็กเกจ ส่วน**โมดูลเดโมกับตัวโหลดของมัน**เป็นของไซต์ ไซต์นี้เก็บตัวโหลดไว้ที่ `src/lib/demo-loader.ts` และเรียก `mountAllDemos()` หนึ่งครั้งจากเลย์เอาต์ การเรียกนี้รันทุกหน้า แต่ chunk ของโมดูลเดโมจะถูกดึงมาเฉพาะหน้าที่มีจุดยึด `[data-demo]` เท่านั้น

เดโมที่รับอินพุตจากพอยน์เตอร์บน canvas ของมันต้องส่ง `interactive` — เวทีจะยึดท่าทางสัมผัสไว้และแสดงกากบาทเล็ง ตัวนี้เป็นแบบเฉย ๆ (เรนเดอร์อย่างเดียว) จึงไม่เปิดแฟล็ก และการปัดนิ้วผ่าน canvas ยังเลื่อนหน้าได้ตามปกติ มันวาดการแทรกสอดของคลื่นจากสองแหล่งกำเนิดด้วยโทเคนหมึกของหน้าเอง จึงเปลี่ยนตามธีมด้วย:

<DemoMount demo="waves/interference" title="เดโม · การแทรกสอดของคลื่นสองแหล่งกำเนิด" canvas={{ w: 640, h: 300 }}>
  <Fragment slot="caption">
    แหล่งกำเนิดจุดสองแห่งปล่อยคลื่นวงกลม ตรงที่สันคลื่นเจอสันคลื่น หมึกกองรวมกัน ตรงที่สันคลื่นเจอท้องคลื่น กระดาษโผล่ให้เห็น ลองสลับธีมดู — เดโมจะจุ่มหมึกใหม่จากโทเคนที่กำลังใช้อยู่จริง
  </Fragment>
</DemoMount>

สัญญาของโมดูลคือ default export หนึ่งตัว `mount(ctx)` ซึ่งคืนฟังก์ชันเก็บกวาด ส่วนตัวโหลดจะแก้ id โมดูลอย่าง `waves/interference` ด้วยวิธีไหนก็ได้ตามใจไซต์ (ที่นี่ใช้ `import.meta.glob`)

## อุปกรณ์ประจำหน้า

คอมโพเนนต์ที่เหลือทำหน้าที่ล้อมกรอบบันทึก ไม่ใช่เติมเนื้อใน:

- `Hero` เปิดบันทึก: kicker ชื่อเรื่องแบบ display บทเกริ่นที่วิ่งผ่านไปป์ไลน์ Markdown เต็มเส้น บรรทัดเมตา และ `tocLabel` เสริมที่เพิ่มแถว "เกริ่น" แบบไม่มีเลขให้แถบข้าง `title` ใน frontmatter ของบันทึกยังคงเป็นชื่อสั้นตามบัญญัติสำหรับ `<title>` และการ์ด ส่วนชื่อบน hero จะยาวก็ได้
- `PartHero` เปิดบทของฮับ — หัวของหน้านี้เองก็คือมัน kicker ของมันไม่มีใครพิมพ์เอง: เส้นทางส่งป้าย "ภาค III · …" ของบทเข้ามาเป็น `props.partLabel`
- `Part` หั่นบันทึกหน้าเดียวยาว ๆ ออกเป็นภาค พรีเซ็ตกำหนดเลขเปลี่ยนมันเป็นแถวกลุ่ม "ภาค II · …" ในแถบข้าง หน้า[[kitchen-sink|รวมทุกองค์ประกอบ]]ถูกหั่นแบบนั้น
- `HubCard` กับ `.hub-grid` คือการ์ดหน้าแรกของฮับ ส่วน `.path` คือกล่องเส้นทางการอ่านของมัน — ทั้งคู่อยู่บน[[components|หน้าภาพรวมของแกลเลอรีนี้]]
- `LocalToc` เรนเดอร์รายการกระโดดในหน้า รับ ToC ได้ทั้งสองทรงที่พรีเซ็ตกำหนดเลขสองแบบผลิต และซ่อนตัวเองเมื่อรายการน้อยกว่าเกณฑ์ที่ตั้งได้ ดูของจริงข้างล่าง บน ToC ของบทนี้เอง
- `SidebarMemory` จำตำแหน่งเลื่อนของแถบข้างไว้ให้ข้ามการโหลดหน้า และจัดรายการปัจจุบัน (`[aria-current="page"]` โดยปริยาย) ให้อยู่กลางจอเมื่อใดที่มันจะหลุดสายตา วางไว้ในกล่องเลื่อนของแถบข้าง หลังมาร์กอัปนำทาง มันรันก่อนการวาดหน้าจอครั้งแรก แถบข้างจึงไม่มีวันกะพริบขึ้นไปอยู่บนสุด แถบข้างของเดโมนี้ก็ติดตั้งไว้
- `LineageSvg` ใส่กรอบ SVG ที่ไม่มีตัวอักษร — ต้นไม้สายตระกูล อนุกรมวิธาน — เป็นการ์ด; แผนภาพที่มีตัวอักษรคือ `FlowDiagram` ด้านล่าง
- `PageFooter` คือตัวพิมพ์เล็กท้ายบันทึก — บรรทัดใต้ทุกบันทึกที่นี่
- ชิ้นส่วนฝั่งเลือกดูอยู่ใน[[components/wiki|บทวิกิ]] ส่วนฝั่ง Markdown ของแกลเลอรีคือ[[kitchen-sink|รวมทุกองค์ประกอบ]]

## LocalToc กับ FlowDiagram ของจริง

`LocalToc` ป้อนด้วย ToC ของหน้านี้เองที่สร้างตอนบิลด์ — ข้อมูลชุดเดียวกับที่แถบข้างใช้ ส่งให้บันทึกในชื่อ `props.toc`:

<LocalToc toc={props.toc} label="ในบทนี้" />

ภาพเดียวกันในรูป `FlowDiagram` — กล่องเป็น HTML ที่ขยายตามตัวอักษร ลูกศรวัดตำแหน่งหลังจัดวาง จึงไม่มีอะไรล้นออกจากกล่องไม่ว่าใช้ฟอนต์ใด:

## FlowDiagram — กล่องที่ขยายตามตัวอักษร

แผนภาพที่มีตัวอักษรให้ใช้ `FlowDiagram` (หรือบล็อก `mermaid`) `<svg>` ที่กำหนดพิกัดด้วยมือพร้อม `<text>` ถูกวาดสำหรับฟอนต์เดียวและพังเมื่อเจอฟอนต์ที่กว้างกว่า — และแต่ละไซต์เรนเดอร์ด้วยฟอนต์ของตัวเอง; `LineageSvg` เก็บไว้สำหรับ SVG ที่ไม่มีข้อความซึ่งฟอนต์อาจดันให้เสียรูป สเปกคือข้อมูล: `cols`, `nodes` (`col` / `row` / `span`, `tone`, `lines`, `tag`, `ghost` สำหรับโน้ตเส้นประ, `mono` สำหรับพาธ), `edges` (`label`, `dashed`, `off` สำหรับเส้นที่ขาด), `lanes` และ `heads` ตามต้องการ:

</FlowDiagram>

## อุปกรณ์ที่ไม่มีคอมโพเนนต์

บางชิ้นเป็นคลาสธรรมดาใน `base.css` สำหรับไซต์ที่เรนเดอร์จากเลย์เอาต์ของตัวเอง หรือเขียนเป็น HTML ในเนื้อความ:

| คลาส | คืออะไร |
| --- | --- |
| `.page-head` + `.kicker`, `.page-desc`, `.page-date` | หัวหน้าที่ขับเคลื่อนด้วย frontmatter (kicker, h1, คำอธิบาย, วันที่) เรนเดอร์โดยเลย์เอาต์แทน `<Hero>` |
| `.banner`, `.banner-fallback` | ประกาศบรรทัดเดียวใต้หัว รูปแบบ fallback คือแบบเสียงเบา |
| `.page-foot` | ส่วนท้ายตัวพิมพ์เล็กสองคอลัมน์ (ช่องซ้าย ช่องขวา) |
| `.speak` | บรรทัดอธิบายภาษาชาวบ้านใต้หัวข้อเชิงลึก ป้ายของมันคือ `--speak-label` |
| `.path` + `.title`, `.route`, `.arrow` | กล่องเส้นทางการอ่านบนฮับ |
| `.ref-tag` | แท็ก monospace เล็ก ๆ ในรายการอ้างอิง (งานประชุม ปี) |
| `.tag`, `.tag.teal / .mustard / .violet` | ตราของการ์ดงานวิจัย ใช้ที่ไหนก็ได้ |
| `.measured` + `.measured-head`, `.measured-body`, `.measured-pane` (`.doc`), `.measured-tag` | การ์ดเทียบ "ตามเอกสาร-ตามการวัด": แถบชื่อสีเขียวหัวเป็ดทึบเหนือสองบาน บาน `.doc` ถือคำอ้าง อีกบานถือผลวัด — เงารูปทรงที่ไม่ซ้ำกับ callout ใด ๆ |
| `.paper .idea-label` | ป้ายแนวคิดหลักตัวพิมพ์ใหญ่เล็ก ๆ ในเนื้อของ `PaperCard` เช่น `<span class="idea-label">Key idea</span>` |
