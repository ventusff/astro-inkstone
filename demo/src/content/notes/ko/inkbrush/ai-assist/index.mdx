## 블록 고쳐쓰기

블록에 마우스를 올려 ✦ 버튼을 클릭한 뒤, 빠른 의도 하나 — 다듬기, 더 엄밀하게, 압축하기, 수식 고치기 — 를 고르거나 직접 지시를 입력합니다. 작업은 서버 쪽에서, 노트 디렉터리의 일회용 사본 안에서 돌아갑니다. 파일 도구는 그 사본에 갇혀 있고 — 셸도 네트워크도 없습니다 — 진행 상황은 실시간으로 스트리밍되며, 브라우저 탭을 닫아도 살아남습니다. 작업이 끝나면 바뀐 파일은 수동 저장과 같은 빌드 관문을 통과해야만 프로젝트로 돌아와 일지에 기록됩니다 — 그래서 [[inkbrush/revisions|⟲]] 버튼으로 무를 수 있습니다.

## 노트에 관해 묻기

채팅 패널(오른쪽 아래에 떠 있는 버튼)은 지금 읽고 있는 노트에 관한 질문에 답합니다. Claude는 읽기 전용 도구 세트로 작업 사본의 소스를 읽고, 이어지는 질문은 같은 대화를 이어 갑니다.

## 노트 전체 번역

노트에 없는 로케일마다, 채팅 패널이 클릭 한 번의 "버전 생성"을 제안합니다 — 글자 그대로의 번역이 아니라, 모든 앵커와 코드 블록과 구조 불변량을 지킨 채 대상 언어로 다시 들려주는 노트입니다. 결과는 그 로케일의 미러 파일로 쓰이고, 무엇이든 남기 전에 빌드 관문이 최종 결정권을 갖습니다. 이 정원은 열여덟 개 언어로 자랍니다; 언어 메뉴는 지금 보고 있는 페이지의 모든 판을 나열하고, 편집 모드에서는 아직 없는 판이 클릭 한 번 거리에 있습니다. 번역은 파일 전체 단위의 변경입니다: 일지가 기록하되, 무르는 일은 ⟲ 클릭이 아니라 git 작업입니다.
