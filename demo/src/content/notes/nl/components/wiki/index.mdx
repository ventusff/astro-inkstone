## De koppeling, drie regels

```ts title="src/lib/taxonomy.ts (de volledige koppeling van deze site)"
import { createTaxonomy } from 'astro-inkstone/lib/taxonomy';
import { DOMAINS, KINDS, STATUSES } from '../content/notes/_meta/taxonomy';

export const { getWikiUnits, groupByKind, groupByDomain, groupByPrimaryDomain, tagIndex, resolveTaxonomy } =
  createTaxonomy({ kinds: KINDS, domains: DOMAINS, statuses: STATUSES },
    { collection: 'notes', locales: [{ code: 'zh', prefix: 'zh/' }], primary: 'en' });
```

De registry (`_meta/taxonomy.ts`) is pure data in de inhoudsboom: soorten, domeinen met toonkleuren, statussen met puntkleuren, elk met een eigen weergavetekst per taal. Voeg daar een waarde toe, hang hem aan een notitie, en elke bladerpagina pikt hem op — de routes zijn immers per waarde geparametriseerd.

## De boekenplank en haar tokens

Bladerpagina's staan op een tweede ondergrond: `browse.css` geeft ze het warme papier, de serif-masthead, de tweepunts planklijn en het kaartenraster, alles via de `--wb-*`-tokens — de plankhelft van [[design-tokens|het palet met twee contexten]]. Een pagina stapt die context binnen met één class, `wb-root`, op haar body; daarbinnen worden de chrome-tokens opnieuw gekoppeld, zodat dezelfde navigatiebalk op beide gronden past.

## NoteCard

## FacetNav

De meerdimensionale bladerindex — soorten, domeinen (met hun tonen), populaire tags, allemaal als voorgerenderde pil-links:

<FacetNav
  base={`${base}/nl`}
  kinds={[
    { def: { id: 'guide', label: 'Gids' }, count: 2 },
    { def: { id: 'reference', label: 'Naslag' }, count: 4 },
    { def: { id: 'pattern', label: 'Patroon' }, count: 1 },
  ]}
  domains={[
    { def: { id: 'design', label: 'Ontwerp', tone: { bg: '#ece7f2', fg: '#5b4a8a' } }, count: 3 },
    { def: { id: 'pipeline', label: 'Pipeline', tone: { bg: '#e3efec', fg: '#2a6f62' } }, count: 2 },
  ]}
  tags={[
    { tag: 'tokens', count: 1 },
    { tag: 'markdown', count: 1 },
  ]}
  active={{ dim: 'kind', value: 'reference' }}
  labels={{ kind: 'Soort', domain: 'Domein', tag: 'Tags', all: 'Alles →' }}
/>

Ook de labelteksten zijn props met Engelse standaardwaarden — het voorbeeld hierboven geeft `labels={{ kind: 'Soort', domain: 'Domein', tag: 'Tags', all: 'Alles →' }}` mee, precies wat de Nederlandse facetpagina's van deze site ook doen; verder verandert er niets.

## TaxonomyLine, KindBadge, StatusDot, DomainChip

De éénregelige metastrook aan het hoofd van een notitie zet de drie badge-atomen in elkaar; elk atoom is ook los te gebruiken:

<TaxonomyLine
  kind={{ id: 'pattern', label: 'Patroon' }}
  domains={[{ id: 'design', label: 'Ontwerp', tone: { bg: '#ece7f2', fg: '#5b4a8a' }, href: `${base}/nl/domain/design/` }]}
  status={{ id: 'growing', label: 'Groeiend', dot: '#5c8a3c' }}
  updated="2026.08"
/>

De atomen op zichzelf, in een doorlopende regel: een <KindBadge def={{ id: 'guide', label: 'Gids' }} /> soortbadge, een <DomainChip def={{ id: 'pipeline', label: 'Pipeline', tone: { bg: '#e3efec', fg: '#2a6f62' } }} href={`${base}/nl/domain/pipeline/`} /> domeinchip, een <StatusDot def={{ id: 'evergreen', label: 'Groenblijvend', dot: '#1f5e46' }} /> statuspunt.

## Backlinks

Het paneel "Gelinkte vermeldingen" onder elke notitie in deze tuin wordt berekend door `createBacklinks` uit het pakket — de eigen wikilink-oplosser van de engine, omgekeerd tot een index van doel ← bronnen, contextfragmenten inbegrepen. Hier met inline voorbeelddata:

## LocalGraph

Dezelfde index beantwoordt nog een tweede vraag — *wat ligt hier één sprong vandaan?* — en `index.localGraph(id, titleOf)` levert het antwoord als een lijst buren, inkomend eerst. Het component tekent ze op een ellips rond de notitie, inkomend met een doorgetrokken lijn en uitgaand gestippeld; een buur mag een eigen `color` meebrengen (uit een tweede collectie, bijvoorbeeld). Hier op kolombreedte, met voorbeelddata; de echte zit in de zijbalk van elke notitie die links heeft:

<div style="max-width: 300px">
  <LocalGraph
    centerTitle="Wiki & bladeren"
    neighbors={[
      { id: 'kitchen-sink', title: 'De staalkaart', href: `${base}/nl/kitchen-sink/`, dir: 'in' },
      { id: 'design-tokens', title: 'Tweelaags palet', href: `${base}/nl/design-tokens/`, dir: 'out' },
      { id: 'three-way-split', title: 'De driedeling', href: `${base}/nl/three-way-split/`, dir: 'out' },
      { id: 'checks', title: 'De controles', href: `${base}/nl/checks/`, dir: 'in', color: 'var(--color-accent4)' },
    ]}
  />
</div>
